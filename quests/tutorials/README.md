# Обучающие квесты Meander

Шесть коротких квестов-учебников. Импортируйте `.mnd` через «Мои квесты → Импорт»
или откройте папку квеста в редакторе.

| Файл | Чему учит |
|---|---|
| `01_variables.mnd` | переменные, типы, формулы, условия, системные переменные |
| `02_text.mnd` | Markdown, обводка текста (цвет/толщина), перенос и масштаб |
| `03_nodes.mnd` | ноды, кнопки, счётчик, таймер ноды, `wait_input` |
| `04_scripts.mnd` | `onQuestStart`, `onNodeEnter`, `onPress`, условия, `for_each`, `onDataChange` |
| `05_save.mnd` | ручные слоты, автосейв и что попадает в сохранение |
| `06_tables.mnd` | сетка, имена строк, вложенные таблицы, `data`, формулы, `table_operation`, `for_each`, `onDataChange` |

`06_tables.mnd` — самый большой: инвентарь, рынок, вложенные характеристики,
песочница покупок/продаж и демонстрация всех табличных функций движка.
