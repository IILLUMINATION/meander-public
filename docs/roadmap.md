# Долгосрочные планы

Записано по запросу: вернуться к этим задачам после текущих фиксов.

## 1. Актуализировать сайт

- Привести `meander.sbs` к текущей версии: возможности редактора, движка,
  плагинов, маркета, форумов, облачных сохранений.
- Обновить скриншоты и демо-квесты под актуальный UI.
- Проверить ссылки: Google Play, AUR `meander-bin`, релизы
  Linux/Windows/macOS, `apps/web_player` (`/play/`).
- Синхронизировать README/сайт: требования Flutter/Rust, сборка, OAuth,
  лицензия AGPL-3.0-or-later.
- Отдельно: страница загрузки и страница «Что нового» из changelog.

## 2. Доделать веб-плеер квестов

- `apps/web_player` на wasm-ядре: проверить полный проход квеста.
- Ассеты: изображения, аудио, видео, шрифты, вложенные таблицы.
- Сохранения: слоты/автосейв в браузере, совместимость с `.mnd`-сейвами.
- Плагины и Lua: что поддерживается в wasm, что явно недоступно.
- Глубокие ссылки `/play/`, параметры квеста, мобильный браузер.
- Производительность: загрузка больших квестов, память, кэш ассетов.
- CI: собирать `libmnd_ffi`/wasm для тестов, чтобы web_player-тесты не
  падали на `Failed to load dynamic library 'libmnd_ffi.so'`.

## 3. Telegram-бот для прохождения квестов

- Bot API: webhook, команды, inline-клавиатуры для кнопок квеста.
- Каталог/поиск квестов, запуск по id/ссылке.
- Привязка аккаунта Meander (OAuth/токен), облачные сохранения и синк.
- Текст, картинки, аудио, таймеры; ограничения сообщений Telegram.
- Сейвы: слоты в чате, продолжение с места, защита от повторной отправки.
- Модерация/рейт-лимиты, логирование, health-check.
- Решить, где живёт состояние: существующий backend или `mnd-server`.
